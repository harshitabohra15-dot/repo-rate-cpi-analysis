# Repo Rate and CPI Inflation Analysis (India)

This project analyses the relationship between the RBI repo rate and CPI inflation in India using monthly data.

## Objective
To visually examine inflation trends alongside monetary policy changes.

## Data Sources
- RBI repo rate data (DBIE)
- CPI index data

## Tools Used
- Python (pandas, matplotlib)

## Key Observations
- This analysis examined the correlation between the RBI repo rate and CPI inflation in India using monthly data from 2016 onwards. The CPI index reveals a smooth and gradually increasing trend over time, which is indicative of sustained inflationary pressures in the economy. On the other hand, the repo rate shows step, like changes, as it is only altered during monetary policy decisions by the RBI. The visual comparison of the two time series suggests that changes in the repo rate are not followed by immediate sharp changes in CPI. This is evidence that a time lag exists between the implementation of monetary policy and its impact on inflation. Indeed, the periods of accommodative monetary policy in 20202021 are consistent with the rise of CPI, whereas the subsequent tightening phases seem to be associated with some lowering of inflation growth. Furthermore, the findings emphasize that inflation dynamics depend on numerous factors besides monetary policy, for instance, supply, side shocks, food and fuel prices, and global economic trends. Hence, though the repo rate is instrumental in influencing inflation expectations, the relationship between the repo rate and CPI is not direct and should be regarded as such.
