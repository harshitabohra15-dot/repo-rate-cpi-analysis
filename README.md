# Repo Rate and CPI Inflation Analysis (India)

This project analyses the relationship between the RBI repo rate and CPI inflation in India using monthly data.

## Objective
To visually examine inflation trends alongside monetary policy changes.

## Data Sources
- RBI repo rate data (DBIE)
- CPI index data

## Tools Used
- Python (pandas, matplotlib)

## Key Observations
- CPI follows a smooth upward trend
- Repo rate changes occur discretely reflecting policy decisions
- Monetary policy impacts inflation with a lag
